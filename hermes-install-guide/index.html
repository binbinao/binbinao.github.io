Hermes Agent 一键安装指导教程

0开始之前

30 秒了解 Hermes 是什么、该选哪条安装路线。

Hermes Agent 是 Nous Research 出品的开源自进化 AI 代理（MIT 协议）——内置学习闭环：从经验中自动创建技能、持久化记忆、搜索过往对话，支持 Telegram / Discord / Slack / WhatsApp / Signal / CLI 多入口，40+ 工具，可接入 300+ 模型（Nous Portal、OpenRouter、OpenAI、Kimi、GLM、MiniMax 等）。

官方提供 两种安装入口，本教程各给一条"一键"路径：

🖥️ 方式一：Hermes Desktop

适合：不想碰终端、偏好图形界面的用户
  • 官网下载 DMG / EXE 安装包，双击即装
  • 会同时装好桌面端 + 命令行（CLI）
  • 支持 macOS 12+ 与 Windows 10/11
  • Linux 无独立桌面安装包（走方式二）

⌨️ 方式二：Hermes CLI

适合：开发者 / Linux 服务器 / 追求可控
  • 一行命令完成全部依赖 + 主程序安装
  • Linux / macOS / WSL2 / Termux 全支持
  • 装完随时可用 hermes desktop 补装桌面端
  • Windows 原生支持为 Beta，可选 WSL2
💡
先想清楚网络环境再选路线：Hermes 安装器需要从 GitHub 克隆仓库。国内网络访问 GitHub 不稳时，桌面安装包可能因下载依赖超时而失败——此时建议先走方式二（CLI 命令行安装，可挂代理重试），装好后运行 hermes desktop 再补装桌面端，成功率最高。

1方式一：直接安装 Hermes Desktop

从官网下载图形界面安装包，双击运行，安装器会自动装好桌面端和命令行环境。

1.1 macOS（12+）稳定

⬇️ 下载 macOS DMG 安装包 🌐 官网下载页
1
下载并打开 DMG

下载 Hermes-Setup.dmg 后双击挂载，将 Hermes 拖入「应用程序」文件夹。

2
首次启动

首次打开若提示"无法验证开发者"，前往 系统设置 → 隐私与安全性，点「仍要打开」。启动后安装器会自动完成依赖安装（Python、Node.js 等）与初始化。

3
完成初始配置

在桌面端引导界面选择模型提供商（推荐 Nous Portal 一键配置），完成后即可开始对话。

1.2 Windows（10/11）稳定

⬇️ 下载 Windows EXE 安装包
1
下载并运行安装器

下载 Hermes-Setup.exe，双击运行，按提示完成安装。SmartScreen 拦截时点「更多信息 → 仍要运行」。

2
启动并配置

安装器同样会装好命令行环境，桌面端启动后按引导选择模型提供商即可。

1.3 Linux

Linux 没有独立的桌面安装包——官方推荐先通过终端安装 CLI（见方式二），再运行一条命令补装桌面端：

bash · Linux
# 先完成方式二的 CLI 安装，然后：
hermes desktop    # 自动安装并启动 Hermes Desktop
⚠️
Linux 桌面端需要编译原生模块，请先确保安装了 g++（Debian/Ubuntu：sudo apt install build-essential）。
🔗
Desktop 与 CLI 是什么关系？两者共享同一个代理核心和记忆（同一 ~/.hermes/ 数据目录）。桌面版 = 图形壳 + 内置 CLI；只用 CLI 也完全够用。任何时候都可以用 hermes desktop 在 CLI 之上补装桌面端。

2方式二：直接安装 Hermes CLI

一行命令搞定：依赖（Python / Node.js / ripgrep / ffmpeg）+ 仓库 + 虚拟环境 + 全局 hermes 命令，全自动。

2.0 安装前置检查（1 分钟）

CLI 安装器唯一的硬性前置是 Git，其余依赖安装器会自动处理：

平台前置条件检查 / 安装命令
macOS Git（Xcode CLT 会自动带） git --version
Linux Git + curl + xz-utils
（安装器以 .tar.xz 下载 Node.js）		 sudo apt install git curl xz-utils
Debian/Ubuntu 示例；用桌面端再加 build-essential
Windows PowerShell（原生 Beta）
或 WSL2（推荐）		 wsl --install
ℹ️
Python、Node.js v22、ripgrep、ffmpeg、uv 都不需要手动装——安装器检测到缺失会自动安装，全程无需 sudo（普通用户安装模式）。

2.1 Linux / macOS / WSL2推荐主路径

终端里执行一行命令：

bash / zsh · Linux · macOS · WSL2 · Termux
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

等价备用源（直连 GitHub raw，与上面二选一）：

bash · 备用
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash

安装完成后，重载 shell 即可启动

bash / zsh
source ~/.bashrc    # zsh 用户: source ~/.zshrc
hermes                # 启动 TUI，开始对话
🌐
国内网络提示：安装过程需克隆 GitHub 仓库并下载依赖，若超时失败，先为终端挂上代理再重跑安装命令，例如 export https_proxy=http://127.0.0.1:7890（端口换成自己的），或改用方式一在可直连的网络环境下安装。

2.2 Windows 原生（PowerShell）Early Beta

v0.14 起原生支持 Windows，PowerShell 中执行：

powershell · Windows 10/11
iex (irm https://hermes-agent.nousresearch.com/install.ps1)
⚠️
生产环境建议走 WSL2：原生 Windows 路径仍在 Beta。更稳的方案是在 PowerShell（管理员）中运行 wsl --install 装 WSL2，然后在 WSL2 的 Linux 终端里执行 2.1 的 curl 命令——体验与原生 Linux 完全一致。低版本 PowerShell 可能出现安装输出乱码，建议先升级 PowerShell。

另注：v0.14 起 Hermes 已发布 PyPI 包，已有可控 Python 环境的用户也可 pip install hermes-agent。

2.3 安装器把东西装到了哪

安装模式代码位置hermes 命令数据目录
普通用户（默认） ~/.hermes/hermes-agent/ ~/.local/bin/hermes（符号链接） ~/.hermes/
Root 模式（sudo 安装） /usr/local/lib/hermes-agent/ /usr/local/bin/hermes /root/.hermes/ 或 $HERMES_HOME

Root 模式为多用户共享机器场景（一台机器一份安装，所有用户可用）；个人使用无需 sudo，默认普通用户模式即可。用户级配置（密钥、技能、会话）始终在各用户自己的 ~/.hermes/ 下。

🖥️
CLI 装完想补桌面端？一条命令：hermes desktop。服务器无桌面环境可跳过。

3安装后配置（两条路线通用）

装好 ≠ 能用，还需配置模型提供商。最快 1 条命令，最全走设置向导。

3.1 最快路径：Nous Portal 一键配置推荐

bash
hermes setup --portal

一条命令完成：OAuth 登录 → 设置 Nous 为提供商 → 开启 Tool Gateway（联网搜索、图片生成、TTS、云浏览器）。一个订阅覆盖 300+ 模型，无需逐个配置 API Key（订阅分 Free / Plus / Super / Ultra 多档）。

3.2 完整设置向导（自带 API Key 的用户）

bash
hermes setup          # 交互式向导，逐步配置模型/工具/密钥
# 或按需单独配置：
hermes model          # 交互式选择模型和提供商（OpenRouter/OpenAI/Kimi/GLM/MiniMax…）
hermes tools          # 配置启用的工具
hermes gateway setup  # 接入 Telegram/Discord/Slack 等消息平台

API Key 存储在本地 ~/.hermes/ 配置中；从 OpenClaw 迁移可运行 hermes claw migrate 自动导入设置、记忆、技能和密钥。

3.3 常用命令速查

命令作用
hermes启动终端 TUI，开始对话
hermes desktop安装并启动桌面端
hermes doctor自检诊断，缺什么、怎么修一目了然
hermes update更新到最新版本（自动识别安装方式）
/skills、/model、/usage对话内斜杠命令：浏览技能 / 换模型 / 查用量

4常见问题排查

先跑 hermes doctor，90% 的问题它会直接告诉你答案。
症状解法
hermes: command not found 重载 shell（source ~/.bashrc 或 ~/.zshrc）；仍不行则检查 PATH 是否包含 ~/.local/bin：
export PATH="$HOME/.local/bin:$PATH"
安装卡在 GitHub 克隆 / 下载超时 国内网络问题。为终端挂代理后重跑安装命令（export https_proxy=…），或切换网络环境
API key not set 运行 hermes model 配置提供商，或 hermes config set OPENROUTER_API_KEY your_key
更新后配置丢失 hermes config check → hermes config migrate
Windows 原生安装输出乱码 升级 PowerShell 到新版本；或改用 WSL2 安装（见 2.2）
ModuleNotFoundError: No module named 'dotenv' 调用了仓库源码而非 venv 启动器——确认执行的是 ~/.hermes/hermes-agent/venv/bin/hermes，运行 hermes doctor 确认
