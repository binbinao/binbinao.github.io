01Hermes Desktop 是什么

一句话：Desktop 不是另一个产品，而是同一个 Hermes Agent 的原生桌面外壳。它和 CLI、TUI、Web Dashboard 共享同一套配置、API 密钥、会话、技能与记忆——在终端聊到一半的会话，回到 Desktop 可以直接续上。

四个前端，一份状态

  • Desktop App — 原生界面，聊天 + 配置 + 管理一体（本篇主角）
  • CLI（hermes）/ TUI（hermes --tui）— 终端界面
  • Web Dashboard（hermes dashboard）— 浏览器管理面板

任何一端开启的会话，都能在另一端恢复继续。

为什么用 Desktop 而不是终端

🖥️ 图形化一切

供应商、模型、工具、密钥都在设置面板里点选，不用手改 YAML。

⚡ 流式工具输出

Agent 干活的过程实时可见，工具调用以结构化卡片展示。

🔭 并排预览

网页、文件、工具输出在右侧预览轨里与聊天同时呈现。

🗂️ 文件浏览器 + 终端

不离开 App 就能浏览工作目录、开终端、看 Git diff。

💡
已装过 CLI？直接跑 hermes desktop 即可启动桌面端，沿用现有配置、密钥、会话与技能，无需重新设置。

02首次启动与引导

首次启动：安装运行时

第一次打开 App，它会自动把 Hermes Agent 运行时装进 HERMES_HOME：

平台路径
macOS / Linux~/.hermes
Windows%LOCALAPPDATA%\hermes

这与 CLI 安装是同一套目录布局——所以两边天然共享状态。

引导页：选择供应商（或稍后再说）

全新引导覆盖层会引导你选择模型供应商。不确定选哪个？点 「Choose provider later」 先进应用，之后再在 Settings 里配置——官方设计就是让你先看界面再决定。

macOS：授权麦克风

系统会弹出一次麦克风权限请求，这是语音模式（Voice Mode）需要的。拒绝也不影响其他功能，之后想开启可去 系统设置 → 隐私与安全性 → 麦克风 里补授权。

完成，进入聊天主界面

看到聊天优先的主窗口即启动成功。若启动失败，查日志：~/.hermes/logs/desktop.log，或终端里 hermes logs gui -f 实时跟踪。

⚡
还没配置供应商？最短路径是在终端跑 hermes setup --portal ——一次 OAuth 登录同时搞定模型 + 四个 Tool Gateway 工具（网页搜索、图像生成、TTS、云浏览器）。详细步骤见配套的《一键安装指南》第 4 节。

03界面导览

Desktop 是聊天优先的窗口布局：中间是对话区，两侧是可折叠的栏。一分钟看懂整体结构：

⬅️ 左侧栏 Cmd/Ctrl+B
  • 会话列表 · Sessions
  • 项目 · Projects
  • Profiles
  • Bots 花名册
  • 导航入口
💬 对话区（主窗口）
  • 会话标签页（多会话并行）
  • 流式回复 + 工具调用卡片
  • 输入框（含模型选择器、麦克风）
  • 对话时间线标记
➡️ 右侧栏 Cmd/Ctrl+J
  • 预览轨（网页/文件/工具输出）
  • 文件浏览器
  • 终端（可多开）
底部状态栏：上下文用量 · 工作区 · 模型 · 审批 · 计时器
Desktop 主窗口结构示意（两侧栏可通过 Cmd/Ctrl+\ 互换左右位置）

多标签 / 多窗口

  • Cmd/Ctrl+T 新会话标签；Ctrl+Tab / Ctrl+Shift+Tab 在会话间轮换；Ctrl+1…9 按位置跳转
  • Cmd/Ctrl+W 关闭标签，Cmd/Ctrl+Shift+T 恢复刚关的，Cmd/Ctrl+Shift+N 开新窗口
  • 任何会话都可以通过右键菜单 「New window」 弹出成独立窗口——Agent 的实时输出会同时流进每个展示该会话的窗口

底部状态栏

状态栏显示会话实时状态，右键可勾选显示项：上下文用量、工作区、模型、审批、回合/会话计时器、终端、Command Center、后端版本。Cmd/Ctrl+Shift+S 可整体隐藏。

⭐ 上下文用量表（Context Meter）

状态栏里的「% 满」指示器实时显示当前会话上下文窗口占用。点击可展开明细：系统提示、工具定义、技能、记忆、规则、MCP、子代理定义、对话各占多少 token——长会话变慢时先看这里。

04跑通第一场对话

官方 Quickstart 的铁律：如果 Hermes 连一场普通对话都完不成，先别叠加任何功能。先拿到一场干净的对话，再去碰网关、cron、技能、语音。

新建会话

Cmd/Ctrl+N 或左上角新建按钮。

选模型

输入框左侧、麦克风按钮旁边就是模型选择器。选一个就够——这个选择会记住（per 设备粘性），跨新会话和重启都跟随，但不会写进 Profile 默认值。

发第一条消息

不知道说什么？官方示例三选一：

PROMPT
用 5 条要点总结当前目录这个仓库，并指出主入口文件在哪。

（或英文原版）
Summarize this repo in 5 bullets and tell me what the main entrypoint is.

也可以更简单：看看我当前目录里，哪个像主项目文件？

观察工具调用

回复过程中你会看到流式输出 + 工具活动卡片——Hermes 调终端、读文件、搜网页的过程全部实时可见。右侧预览轨可能同时渲染出工具输出。

验证会话存活

关闭后再进来，会话还在；终端里 hermes --continue 也能续上同一场对话——这就是「四端共享状态」的直接证据。

✅ 「第一场对话成功」官方检查清单

  • 横幅显示了所选模型 / 供应商
  • Hermes 无报错地回复了
  • 需要时它真的调用了工具（终端 / 文件读取 / 网页搜索）
  • 对话正常延续了不止一轮

四条全过 = 你已经跨过了最难的部分。

05对话进阶技巧

输入框（Composer）

  • 拖拽附件：把文件直接拖进聊天区域任意位置，即附到下一条消息
  • 历史提示召回：输入框为空时按 ↑ / ↓ 翻出之前的 prompt 复用
  • 消息排队：Agent 干活时可以继续输入排队；按 Esc 暂停队列并展开列表——排队消息支持发送前编辑、单条发送或删除
  • 打断：直接发一条新消息即可打断当前任务转向新指令

查找与导航

  • Cmd/Ctrl+F 页内查找聊天记录，Enter/Shift+Enter 及 Cmd/Ctrl+G 逐个跳匹配
  • 对话时间线轨道：聊过几轮后，对话区边缘出现一列小标记（每个对应一条 prompt），悬停展开 prompt 列表，点击直接跳转到那个位置
  • Cmd/Ctrl+Shift+F 跨会话搜索

模型切换须知

行为说明
输入框选模型粘性 UI 状态（per 设备记忆），跟随新会话与重启；不写入 Profile 默认
会话中途切换只作用于当前这场对话
设全局默认Settings → Model，作用于新会话、cron、子代理与辅助任务
中途切模型的代价会重置提示缓存——整段对话按完整输入价格重新计费读一遍
推理力度/快速模式每个模型分别记住自己的 effort 与 fast 预设

斜杠命令照样能用

Desktop 聊天兼容终端的斜杠命令体系。输入 / 会弹出自动补全列表。新手最常用的几个：

命令作用
/help列出全部可用命令
/tools查看当前可用工具
/model交互式切换模型
/save保存当前对话
/journey打开记忆星图（见第 6 节）

06六大核心功能

这是 Desktop 相对终端的真正增量价值，按日常使用频率排序。

🔭

① 右侧预览轨（Preview Rail）

聊天时，Agent 打开的网页、生成的文件、工具输出在右侧栏并排实时渲染——不用在聊天和结果之间来回切换。这是「边聊边看」的核心体验。

Cmd/Ctrl+J 开关右侧栏

🖼️

② Artifacts 产物画廊

所有会话生成的图片、文件、链接自动汇入一个可搜索的画廊视图；每件产物标注来源会话，点击可跳回当时的那场聊天；图片和文件支持预览、下载、复制、在浏览器打开。

入口：左侧栏 或 命令面板 → 「Artifacts — Browse generated outputs」

⌨️

③ 内置终端 + Add to Chat

右侧栏内置终端，可多开、隐藏时 shell 不被杀掉。杀手锏是 「Add to chat」：选中终端输出，一键送进输入框作为下一条消息的上下文——排查报错时极其顺手。

Ctrl+` 开终端 · Ctrl+Shift+` 再开一个 · Ctrl+Shift+↓/↑ 终端间切换

🌿

④ Git 审查面板与 Worktree

不用离开 App 就能看分支领先/落后、变更文件列表与 diff（可按 未提交 / 本分支 / 上一回合 三种范围过滤——「上一回合」= 只看 Agent 刚才这轮改了什么）。支持暂存/撤销、自动生成 commit message、Commit & Push、经 gh 建 PR，或干脆让 Hermes 代劳开 PR。还能一键建 Git worktree 开平行分支。

Cmd/Ctrl+G 审查面板 · Cmd/Ctrl+Shift+B 新建 worktree

🎙️

⑤ 语音模式

点输入框旁的麦克风按钮进入——对话，Hermes 回话可听。与 CLI / Telegram / Discord 的语音模式同一套后端。macOS 首次使用需授权麦克风。

模型选择器位于麦克风左侧，语音会话同样可换模型

🌌

⑥ 记忆星图（Memory Graph / Star Map）+ 学习闭环

Hermes 的招牌：它从经验中自动创建技能、使用中自我改进、跨会话沉淀对你本人的认知。星图把这些学到的技能与记忆渲染成可缩放的节点星座图 + 时间线，按 All / Used / Learned 过滤，节点可编辑可删除。在聊天里输入 /journey 还能带播放进度条回放学习历程。

入口：命令面板 → Memory Graph，或聊天中 /journey

两个「全局随时呼出」的效率神器

🪟 HUD 悬浮模式

Cmd/Ctrl+Shift+H 把聊天剥离成一个无边框置顶小条。位置本身就是语境——问「这个」「这页」时，Hermes 知道你指的是下方的应用和屏幕。Cmd/Ctrl+Shift+G 全局快捷键把 HUD 吸附到鼠标处。

⚡ Quick Entry

系统级全局热键，任何应用里按 Ctrl/Cmd+Shift+Space（默认，可改键）呼出一个迷你输入框随手问 Hermes。在 Settings → Advanced → Quick Entry 开启。

08设置要点

Cmd/Ctrl+, 打开设置。新手最需要知道的几页：

Providers — 账号与密钥

图形化的「账户 / API Key」页：支持 Nous Portal OAuth、OpenAI Codex 设备码、Anthropic OAuth、xAI Grok OAuth 等浏览器登录流，也可以直接粘贴各家的 API Key。密钥写入 ~/.hermes/.env。

⚠️
Hermes 要求模型至少 64K token 上下文，小窗口模型会在启动时被拒。本地模型记得把 ctx size 调到 ≥ 64K（如 Ollama 加 -c 65536）。

Model — 全局默认模型

这里是真正的默认模型所在（输入框那个选择器只是设备级 UI 偏好）。默认模型作用于新会话、cron 任务、子代理和辅助任务。

Gateways — 本地 / 远程 / 云端

Desktop 默认自己拉起并管理一个本地后端。进阶玩法是指向别处：

  • Remote gateway — 填远程 hermes serve 地址（VPS、家里的小机器、Tailscale 网内的 Mac mini），Agent 跑在远程、你在本地聊
  • Hermes Cloud — 登录一次即列出账号下的所有 Agent，无需粘贴 URL
  • 多网关注册表 — 给每台机器起名（Homelab、Work laptop…），侧栏一键切换；令牌加密存在系统钥匙串里

其他值得一逛的

  • Appearance — 主题（含从 VS Code Marketplace 实时搜主题下载转换）、终端字体（Nerd Fonts 如 MesloLGS NF 可正确渲染图标）
  • Advanced → Keep computer awake — 长任务跑着不让机器睡眠
  • Keyboard Shortcuts（Cmd/Ctrl+/）— 全部快捷键可自定义，冲突会被标出
  • Plugins — 管理桌面端插件（单个 ESM 文件即装即热载）与后端 Agent 插件

多 Profile 的「Applies to」作用域

配置型设置页（Model、Workspace、Safety、Memory & Context 等）顶部有一排 Profile 芯片：不用切换整个应用，就能直接查看/修改另一个 Profile 的设置——多实例用户防串台的保险。

10排错与恢复

看懂错误卡片：按层定位

回合失败时，聊天里会出现一张点名失败层的错误卡片：供应商/模型、自定义端点、流式连接、认证、计费、网关、本地运行时、磁盘——一眼知道是哪家的问题。卡片附带动作：

  • Retry — 重跑失败回合
  • Switch provider — 直达 Settings → Models
  • Open logs — 打开 ~/.hermes/logs
  • Send diagnostics — 上传脱敏诊断包给官方（显式确认后才发，密钥全程脱敏，14 天自动删除）
  • Copy error details — 复制纯文本错误摘要

高频问题速查

症状可能原因解法
能打开但回复空白/破碎供应商认证或模型选择错了Settings → Providers 重配；确认模型与密钥匹配
App 完全启动失败运行时/venv 损坏看 ~/.hermes/logs/desktop.log；重建 venv：rm -rf ~/.hermes/hermes-agent/venv 后重启
想重走首次引导—rm ~/.hermes/hermes-agent/.hermes-bootstrap-complete 再启动
macOS 麦克风权限卡死TCC 授权状态异常tccutil reset Microphone com.nousresearch.hermes，重启 App 重新授权
远程连接 401 / Invalid credentials账号密码不匹配或认证门未启用核对 ~/.hermes/.env；curl -s http://<host>:9119/api/status 应报 auth_required:true
每次重启都被登出（远程）缺稳定签名密钥在远端 .env 设 HERMES_DASHBOARD_BASIC_AUTH_SECRET
自建/构建时卡在 Electron 下载GitHub 被墙/限速安装器会自动换 npmmirror 镜像重试；也可自设 ELECTRON_MIRROR

官方恢复套路（按顺序来）

TERMINAL
$ hermes doctor          # 1. 体检：配置哪里坏了
$ hermes model            # 2. 重确认供应商/模型/认证
$ hermes setup            # 3. 重跑设置向导
$ hermes sessions list    # 4. 确认会话都在
$ hermes --continue       # 5. 续上最近会话
$ hermes gateway status   # 6. 网关状态（如用到）

这套顺序能把「玄学坏了」拉回已知状态。

更新与卸载

  • 更新：后台自动检查，就绪后一键更新；多目标时（本地后端 + 桌面端）About 面板的 Update now 会按「后端先、桌面端最后」的顺序全部更完
  • 卸载：Settings → About → Danger zone 三档——①只卸聊天 GUI（Agent、配置、会话保留）②卸 GUI + Agent（保留用户数据）③全部卸载。终端等价：hermes uninstall --gui / hermes uninstall / hermes uninstall --full
